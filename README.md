# Global Insight - Portal de Noticias (Demostración de Seguridad)

Proyecto de prueba de concepto y demostración interactiva desarrollado con fines educativos y de concientización en ciberseguridad.

## 📋 Descripción

Simula un portal moderno de noticias internacionales (*Global Insight*) que integra mecanismos de demostración sobre:
- Consentimiento de cookies y almacenamiento local.
- Registro y autenticación mediante Firebase.
- Envío de eventos y telemetría a endpoints de prueba (webhooks).
- Interfaz responsiva con diseño editorial moderno.

> **Nota:** Este proyecto fue diseñado exclusivamente para entornos académicos, ferias de proyectos y demostraciones de ingeniería social y seguridad informática.

## 🚀 Tecnologías

- **HTML5 / CSS3 / JavaScript (Vanilla)**
- **Firebase SDK** (Auth / Firestore)
- **FontAwesome** y **Google Fonts**

## 💻 Ejecución Local

1. Clona el repositorio:
   ```bash
   git clone https://github.com/saolos12/portal-noticias-seguridad-demo.git
   ```
2. Abre el archivo `index.html` en cualquier navegador web o mediante una extensión como *Live Server* en VS Code.
